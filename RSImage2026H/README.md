# 遥感图像处理 Demo

用 Visual Studio 打开 `RSImage2026H.slnx`，运行 `RSImage2026H`。程序会在项目目录中自动加载 `准备/testdata/TMtest.tif`；也可以点击左侧“加载图像”选择其他 GDAL 支持的影像。

左侧的 R/G/B 下拉框用于选择彩色合成波段，点击“显示图像”重新渲染。默认 TM 假彩色组合为 4/3/2。选择“灰度”波段后，在“基本操作”页点击“显示单波段”。

各栏目提供以下操作：

- 颜色及灰度处理：灰度、反相、伪彩色。
- 图像校正：亮度、Gamma、旋转、翻转、平移的预览处理。
- 图像变换：NDVI、NDWI、单波段显示。
- 图像增强：直方图均衡化、均值平滑、锐化。
- 图像分类：K 均值非监督分类、灰度阈值分类。
- 信号提取：NDVI 植被掩膜、NDWI 水体掩膜、Sobel 边缘。
- 图像压缩：按质量参数保存 JPEG，也可保存 PNG。
- 形态学处理：二值化、膨胀、腐蚀、开运算、闭运算。
- 格式转换：将当前预览保存为 PNG、BMP 或 TIFF。
- 图像质量评价：当前预览相对原始合成图的 MSE、PSNR，以及灰度熵。

界面处理的是最长边 1600 像素的预览图，不会改写原始影像。NDVI/NDWI 使用原始波段值计算。预览导出的 PNG、BMP、TIFF、JPEG 不含原始地理坐标；“图像校正”栏目也不是大气校正或地理配准。
